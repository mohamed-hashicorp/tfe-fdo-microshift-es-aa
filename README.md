# Terraform Enterprise on MicroShift

This repository contains the configuration and resources required to deploy **Terraform Enterprise** on **MicroShift**.

The deployment steps and overall approach used here are based on the work from the following repository:  
https://github.com/munnep/tfe_fdo_microshift
